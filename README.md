
# AI-Powered Business Decision Intelligence Platform

## Overview
An interactive business analytics dashboard built using Python and Streamlit. It transforms raw business data into meaningful insights through data cleaning, KPI analysis, interactive visualizations, and business recommendations.

## Features
- Upload CSV and Excel datasets
- Automated data cleaning and duplicate removal
- Dataset preview and data information
- Business KPI calculations
- Automated business insights
- Business recommendations
- Interactive data visualizations
- Sales analysis by region
- Sales analysis by product
- Profit analysis by region
- Download cleaned dataset

## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly
- NumPy
- Scikit-learn

## How to Run

1. Install Python.
2. Install the required libraries:

   pip install -r requirements.txt

3. Run the application:

   python -m streamlit run app.py

4. Upload your CSV or Excel business dataset.
5. Explore the dashboard, insights, KPIs, and charts.

## Objective
The goal of this project is to simplify business data analysis and support data-driven decision-making through an interactive analytics dashboard.
